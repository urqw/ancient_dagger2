# Ancient Dagger 2

Text-based game "Ancient Dagger 2" (Russian: "Древний кинжал 2") by Kaschey (Russian: Кащей) and RipOs.

The game is in Russian, developed for RipURQ, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/#ancient_dagger2).

The game was first published on January 4, 2001.

Interactive fiction identifier (IFID) of the game which is its MD5 hash: 473975B7277F7CA6FE65E109C21272F3

## Description

Продолжение фэнтезийного сюжета о бравом хоббите Фреде. Взяв в свои маленькие мохнатые лапки злополучный древний кинжал и записку, накинув на плечи плащ и собрав ещё не израсходованные в прошлой серии остатки храбрости, наш хоббит сел в лодку и двинулся в Разлог на встречу новым приключениям.
